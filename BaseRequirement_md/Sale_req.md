# Sale Requirement

## Flow

1. Create QT (Quotation)
2. Send QT to Customer
3. Receive PO (Purchase Order) from Customer
4. Create SO (Sale Order) — referencing the QT and customer PO
5. Send SO to Factory (as production request)
6. Receive Finished Goods from Factory
7. Sale Delivery to Customer

## Master Data (basic data required, like every ERP)

- **Customer** — code, name, address, tax id, contact, payment terms
- **Product** — code, name, unit of measure, price, category
- **Price List** — product price per customer / customer group
- **Employee / Sales Person** — who owns the QT/SO
- **Warehouse** — delivery source location
- **Document Numbering** — running number per document type (QT, SO, DN)

## Documents

### QT (Quotation)

- QT No., Date, Customer, Sales Person
- Lines: Product, Qty, Unit Price, Amount
- Status: Draft -> Sent -> Accepted / Rejected / Expired

### Customer PO

- Reference document only (uploaded/recorded, not generated by the system)
- PO No. (from customer), PO Date, attached file/reference

### SO (Sale Order)

- SO No., Date, Customer, reference QT No., reference Customer PO No.
- Lines: Product, Qty, Unit Price, Amount
- Status: Draft -> Confirmed -> In Production -> Ready to Deliver -> Delivered -> Closed / Cancelled

### Delivery (DN - Delivery Note)

- DN No., Date, SO reference, Customer
- Lines: Product, Qty delivered
- Status: Draft -> Delivered
